Sistema de Modulación en Amplitud (AM)

 Introducción
Este proyecto consiste en implementar un sistema de modulación en amplitud (AM) utilizando Python y Google Colab.

El objetivo es comprender cómo funciona la modulación AM y analizar el comportamiento de una señal durante su transmisión.

Herramientas utilizadas
- Python
- Google Colab
- NumPy
- Matplotlib
- SciPy
- GitHub

Desarrollo del proyecto

Se realizaron las siguientes actividades:

1. Importación de las librerías necesarias.
2. Creación de una señal de información de baja frecuencia.
3. Implementación de la modulación en amplitud (AM).
4. Análisis de la señal en el dominio de la frecuencia mediante FFT.
5. Evaluación del efecto del ruido.
6. Análisis de atenuación.
7. Análisis de distorsión.

Resultados

Se generaron gráficas para observar la señal original, la señal modulada y los cambios producidos por el ruido, la atenuación y la distorsión.

Conclusión

Con este proyecto se comprendió el funcionamiento de la modulación en amplitud y la importancia de analizar las señales en los sistemas de comunicación. También se observó cómo diferentes factores pueden modificar una señal durante su transmisión.
